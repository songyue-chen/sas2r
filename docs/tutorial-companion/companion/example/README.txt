Tutorial example for sas2r

This example is supplied with the separate companion scripts. It uses
SET raw.input_ds for explicit input discovery and LENGTH AVAL_FLAG $8
so the full RECORDED value is retained. Bundled package examples are
available under examples/migration-demo.

expected-final.csv contains hand-authored expectations derived from this
SAS and make-input.R. It was not produced by SAS and must not be
represented or configured as an independent SAS reference. Verification is
performed after translation; it is not supplied as an answer to the translator.
