In this tutorial, we’ll set up sas2r with OpenAI and run a SAS-to-R migration in RStudio. Along the way, we’ll check the model connection, review the generated outputs, and export the R code to run on its own.

Download the companion scripts and matching example below to follow along. These are separate from the examples included in the sas2r package. The walkthrough uses synthetic data and recreated interfaces.
