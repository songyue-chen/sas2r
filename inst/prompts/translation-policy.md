Shared source-translation policy (translator, static reviewer, fixer):
- Preserve executable SAS behavior. Reference comparison answers are not a translation specification. Do not infer desired rows, counts or values from a comparison mismatch.
- helper_use lists actual sas2r runtime helper calls only. Ordinary allowed package functions, local functions and selected project functions are not runtime helpers. Metadata normalization must not require rewriting valid code. Call selected dependencies instead of silently copying or replacing their behavior.
- Use the source-owned macro interface. Bare trigger-free text defaults such as 260mm or a+b are text, not R expressions. Unresolved expansion is unknown; NULL or an empty string does not solve it. A bare formal plus missing() handling may be appropriate, but does not certify unsupported omission behavior.
- Missing information is not proof of wrong code. Review finding categories never prove success or cancel independent mechanical/runtime failures.
- Package facts distinguish allowlisting, observed installation/version and documented capability. Inspect supplied selected dependency implementations rather than guess their return types. Missing/truncated bodies establish no return guarantee; an unrelated package fact cannot excuse a defect.
- The shared packet already fills available direct-dependency context within fixed limits. When the required body remains missing/truncated, keep the uncertainty visible; do not rewrite code to guess the omitted behavior or repeat an unchanged request. Unsupported-capability claims without independent facts remain unverified.
- Reuse supported operations; never replace banned parse/eval with a handwritten general SQL/WHERE interpreter. A banned implementation may have a simple supported replacement. Never drop required filtering, specialize to observed data, or claim general macro equivalence from an empty-filter example. Keep unsupported behavior explicit.
- A model-only claim that runnable SAS has a syntax error must not become an intentional R stop. SAS macro quoting can mask unmatched punctuation: %str(%() quotes an opening parenthesis. The offline parser is not a SAS compiler. Trace mutated macro values through the next loop condition rather than continue over an assumed original token list. A proposed behavioral reversal needs a concrete source operation and counterexample; a previous or later reviewer opinion is not authority.
- PROC SQL COUNT(DISTINCT x) excludes missing values. Preserve dependency delegation and the dependency's actual return convention. Dataset existence is distinct from readable/populated data; use lib_exists for supported registry members. A valid empty dataset can be correct.
- Numeric display helpers are limited to their documented scope. Field width is not significant-digit count; do not invent a full SAS BEST formatter or change numeric values to make display easier. Cosmetic figure refinement belongs to humans.
- Advisory code-symbol and direct-I/O notices do not establish defects and do not independently authorize repair. Reviewer remains static and read-only; no new tools or data access are provided.
